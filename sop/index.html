02The reference set

Four real photographs per row, plus the approved Velano image where one exists. Attached unmodified. This is the part that was wrong for the longest.

Never tone-map a reference

The contract states the finish comes from a photograph, never a colour word. An early pipeline ran a levels stretch across the product reference before attaching it, so the finish the model saw was one we had altered. Measured on the Vanta Oak reference, saturation went 48.4 to 72.0 percent and Oak rendered as a red walnut. References go in as the camera made them.

ColumnWhat it isWhat it carries
Approved VelanoThe signed-off image for this exact shot Composition, room, light direction, camera, crop. Leads when the family has one. A buyer comparing finishes must see the same photograph with only the wood changed.
QReal camera photograph of the real product Realism only. Attach as a cropped surface patch, never full frame. See the trap below.
PProduct on plain whiteTrue form and silhouette. Its studio lighting must not appear in the output.
RFinishes side by side, labelledTrue colour, taken from the labelled finish only.

Worked example · The Arbor, Agate Grey, 14 dia x 20 in

Trap: the room goes to the strongest scene signal

Attaching Q full frame put a real room in front of the model and it copied that room instead of the approved one. Ranked against outcomes, only the densest donor survived: 51.6 won on all three cells, 38.4 lost on all three, 26.5 lost on one of three, 9.7 lost on all three. Crop Q to a square patch of solid timber at native resolution and the environment reference wins unopposed.

Trap: never upscale the texture patch

The first patch cropped 34 percent of the object and magnified it to 768px, which on one product was 141 native pixels blown up 5.4 times. That fed the model a blurred surface and it faithfully reproduced the blur. This is the entire cause of the "too smooth, not enough grain" complaint. Crop larger, resample down only, never up.

03How a reference becomes an approved image

The references do not go in as "inspiration". Each one is assigned a single job in the prompt, and every property of the finished image is traceable to the reference that governs it. This is the whole method.

StepWhat happens, and why it is that way
1Resolve the row Look the variant up by canonical id in column A. Read family, finish, size, and the four reference URLs. Never by row number.
2Pick the environment donor The approved image for this shot, from the catalogue standard. Same room for every product in that column.
3Crop Q to a surface patch Slide a square window over the piece, keep the position with the most solid timber, at native resolution. Purity measured 0.93 to 1.0. Carries real lens rendering with no room attached.
4Assemble the prompt Three blocks, built from the row, never hand-written. See the anatomy below.
5Generate All references attached as an ordered array, 1536x2048, medium quality.
6Check, then publish Environment and colour measured against calibrated thresholds. Fail means regenerate, not accept.

Why the prompt is generated and never typed

Every block here was proven on a re-run, and the generic version of the same instruction is recorded as having failed. Adjectives do not transmit proportion; a number and a named failure mode do. Hand-writing a prompt per cell means the contract lives in someone's head, which is how a studio requirement and a studio prohibition ended up in the same prompt for months.

04The five shots

The environment belongs to the column, identical across every product. It does not belong to the family. Variation lives in the piece and the finish, never the set, because a buyer scans a column.

1

Studio

Seamless warm neutral backdrop, greige or taupe, falling off gently. Floor and backdrop meet in a soft curve with no corner or skirting. Soft contact shadow. No furniture, no window, no rug. Never pure white.

CHECK border structure ≥ 20 · known-good 22.4 to 29.0, soft by design

5

Corner beside a window

Two plaster walls meeting, daylight falling directly across the piece and throwing its shadow along wall and floor.

Second worked example · The Solen, Walnut, 12 x 12 x 20 in · square plan, different wood, same five environments

Two different products, two different woods, one set of five environments. That is the whole point: a buyer scanning column 3 sees the same room every time and only the piece changes.

Approved props

Books, candles, plants, flowers, cups, picture frames, a draped cloth. Nothing else is invented. Props stay minimal and never obscure the form.

Greenery

Worked in deliberately to contrast against the wood: a plant or cut flowers on or beside the piece, and real foliage visible through any window in shot.

05Prompt templates

The exact text sent to the model, generated from the row. Placeholders are the only thing that changes between cells. Copy a template, fill the five tokens, attach the references in order, and the output is an approved image.

A template is a claim about output, and the only evidence for it is output. Diff any change against the as-run prompt, then generate against it, before it goes in here.

THE ENVIRONMENT FOR THIS SHOT IS FIXED BY THE CATALOGUE AND IS THE SAME FOR EVERY PRODUCT IN THIS POSITION.

THIS IS A STUDIO PHOTOGRAPH, NOT A ROOM. The piece stands alone on a seamless studio backdrop in a warm neutral tone, a soft greige or taupe, lit so the backdrop falls off gently from light behind the piece to slightly darker at the edges of frame. The floor and the backdrop meet in a soft seamless curve with no visible corner, no skirting, no wall join. A soft grounded contact shadow sits under the piece. There is NO furniture, NO window, NO rug and NO room of any kind. The backdrop is warm neutral and must NEVER be pure white. Every image 1 in this catalogue uses this same studio, so it must match the others exactly.

THE WOOD GRAIN MUST BE VISIBLE AND MUST READ AS THE SAME TIMBER AS THE REFERENCE PHOTOGRAPHS. Show the FIGURE: the long directional streaks and bands of light and dark that run through this species, the darker heartwood sweeping against paler sapwood, growth rings where a face cuts across them, knots, and the fine checks that open along the grain. The tone is not uniform anywhere on the piece; it varies continuously along the figure. Light must rake across the surface enough that the grain casts its own micro relief. A piece that reads as one even colour with a smooth polished surface is WRONG, however photoreal it otherwise looks, because it loses the thing the buyer is paying for.

THE REFERENCE IMAGES ATTACHED ARE REAL PHOTOGRAPHS OF THE REAL PRODUCT. THEY DO DIFFERENT JOBS.

REFERENCE 1 IS THE APPROVED PHOTOGRAPH FOR THIS EXACT SHOT. It carries the composition, the room, the light direction, the camera position and the crop. Reproduce all of it. A buyer comparing two finishes must see the SAME photograph with only the wood changed, so the set does not change. Vary the camera slightly if you must, never the room.

REFERENCE 2 IS A REAL PHOTOGRAPH TAKEN WITH A REAL CAMERA IN A REAL ROOM. It is the standard for realism. Match how a real camera renders an interior: the way daylight actually falls and falls off across a wall, real shadow density and real shadow edges, real texture on plaster and floor and fabric, the ordinary unevenness and imperfection of real materials, real depth of field, real white balance. Do NOT produce a cleaner, smoother, warmer, more evenly lit or more colour graded room than a real photograph has. A room that looks styled, glowing or perfectly even is WRONG.

REFERENCE 3 IS THE PRODUCT ON PLAIN WHITE. It carries the true form and the true silhouette. Take the shape from this, and take nothing else from it: its lighting is studio lighting and must not appear in your output.

REFERENCE 4 SHOWS THE AVAILABLE FINISHES SIDE BY SIDE, each one labelled. The finish for this piece is {FINISH}. Find that label and take the wood colour from THAT piece only. Never take a colour from a colour word, and never invent a tone. If the named finish is a brown wood, it must read as warm brown, never grey, silver, ashen or desaturated.

REFERENCE 5 IS THE DIMENSIONED DRAWING and the numbers printed on it are the true measurements of this piece. The proportions you draw must match them.

A HERO PRODUCT PHOTOGRAPH. Three quarter view, the whole piece in frame, standing on the floor of the room. The silhouette must read cleanly from top to base with nothing crossing it.

COME IN CLOSE. The piece is the subject and it should FILL the frame: about three quarters of the frame height, top and base both comfortably inside the edges with only a modest margin. The room is present around it as context, not as the subject. A buyer has to be able to inspect the carving, the edges and the grain at this distance, so do not stand back and photograph the room with the piece somewhere in it.

TWO REFERENCE IMAGES ARE ATTACHED AND THEY DO DIFFERENT JOBS.

THE FIRST REFERENCE gives the PHOTOGRAPH: the room, the wall, the floor covering, the furniture and where it sits, the camera height and distance, the focal length, the crop, and the direction and quality of the light. Reproduce all of that. A buyer comparing two finishes has to see the same photograph with different wood in it, so the set must not change.

THE SECOND REFERENCE gives the OBJECT: its true form, its true proportions and its true colour. Take the finish from this photograph. Do NOT take the finish from any colour word, and do NOT take the shape from the first reference.

THE PROPORTIONS ARE {W} INCHES IN DIAMETER BY {H} TALL, so it stands {RATIO} times its own width. This is a SHORT, STOUT, GROUNDED piece, not a tall slender pillar.

CHECK THE PROPORTION IN THE FINISHED FRAME, and measure the SIDE of the piece, not its whole silhouette. Measure from where the piece meets the floor up to the NEAR edge of its top surface, the front lip closest to the camera. Do NOT measure up to the far edge of the top: the camera looks slightly down, so the top reads as an ellipse and its far edge sits higher in the frame than the piece actually is. That is the single most common way this check is failed. The plan of this piece is a CIRCLE, so it shows the same width from every angle and no viewing direction makes it narrower. So that side height divided by the width must be {RATIO}. Taller than {RATIO} is WRONG and the piece must be drawn wider and heavier. Every failure of this piece so far has been toward too tall and too narrow, never toward too squat, so err deliberately toward broad. The form is {FORM from family_forms.py}. It is NOT {ANTI-FORM from family_forms.py}.

MASS IS A SEPARATE PROPERTY FROM PROPORTION AND IT IS THE ONE THAT GETS LOST.

The ratio governs the bounding box and says nothing about how much material fills it. This piece is carved from ONE HEAVY SOLID BLOCK and it must still look like one. Any strands or uprights are BROAD AND FLESHY, as thick as the gap beside them. Any opening is a SMALL TIGHT gap rather than a wide window, and you cannot see much of the room through it. The top slab is THICK with a visible chunky edge. The base is a substantial block, as wide as the top, planted flat on the floor. It should look heavy enough that you would struggle to lift it with one hand.

Do NOT slim the waist. Do NOT thin the strands into ribbons. Do NOT enlarge the void. Do NOT make it an elegant narrow hourglass. It must not read as a slender sculptural pedestal.

Measure the thickness against the SECOND reference: the uprights must be at least as thick, and the openings between them at least as small, as that photograph shows. Erring toward heavier is correct; erring toward slimmer is the failure.

THIS IS A DIFFERENT PHYSICAL PIECE OF WOOD, CUT FROM A SEPARATE BOARD.

These are individually carved solid timber pieces and the character of the grain is what says so. Do NOT copy the reference's grain figure, its surface checks, its knots or its sapwood. Invent this piece's character fresh:
  - the grain figure and the direction it runs
  - the number of surface checks, and each one's length, angle and position
  - where the knots fall, if any
  - which edge the pale sapwood band enters from
  - the mineral streaking

The checks in particular must differ from the reference in COUNT, ANGLE, POSITION and LENGTH. Two pieces carrying the same crack in the same place look manufactured, and that undoes the entire claim these photographs exist to make.

THE SURFACE IS HAND-OILED SOLID HARDWOOD AND IT MUST READ AS ONE.

The oil finish leaves the harder latewood standing very slightly proud of the softer springwood, roughly half a millimetre of relief. Render that: a thin highlight along each lit ridge and a hairline shadow behind it. Carry the chatoyance, the shimmer going brighter where the fibres run toward the light and deeper where they run away, because that shift is what says hardwood more than the pores do.

THE PORES MUST BE SCATTERED AND NOT ARRANGED. No rows, no arcs, no chevrons, no scallops, no bands. Three or four crowded together here, a bare stretch there, one large isolated pore somewhere. Large areas with almost no visible pores at all, which is what makes the porous areas believable. If any part of the surface shows an obvious repeating rhythm, it is wrong.

Not snakeskin, not embossing, not stamped leather, not a machined pattern, not a texture map. Keep the relief FINE and the light SOFT. No crunchy over-sharpened micro contrast, no HDR, no sandblasted or wire-brushed look, no plastic or waxy sheen.

THIS IS LIT LIKE A STUDIO PRODUCT PHOTOGRAPH, NOT LIKE A ROOM.

One broad soft key from slightly above and to one side, with enough fill that the shadow side still shows its carving. The backdrop falls off gently, brighter behind the piece and a little darker toward the edges of frame. A soft grounded contact shadow sits under the piece where it meets the sweep. No window, no shaft of daylight, and no cast shadow from anything outside the frame. The piece is the brightest thing in the picture and the backdrop never competes with it. 

THE WOOD MUST HOLD ITS TEXTURE AT THIS VIEWING DISTANCE. This is a Phase One medium format back at f/5.6, which resolves pores and grain across the entire piece even in a full product view. The surrounding room may go soft; the wood may not. If any area reads as a smooth plastic-like or stone-like fill, the image has failed.

NOT ACCEPTABLE: a pure WHITE background of any kind, a blown out or clipped backdrop, a hard visible line where wall meets floor, skirting, a room corner, a window, a rug, furniture, or any other room detail. No CGI or 3D render look. No visible text, no watermark, no warped verticals, no floating piece. The backdrop is a warm neutral seamless sweep and it stays one continuous surface curving from behind the piece down underneath it.

THE LIGHT LANDS ON THE PIECE. Place the piece IN the light, never beside it. The daylight that brightens the wall and the floor must fall across the product with the same strength. The wood should read as the brightest, richest, most clearly lit object in the photograph, so that the eye goes to it first and the room reads as a setting that shows it off.

THE TEST, AND IT IS THE ONE THIS KEEPS FAILING: if the brightest area in the finished frame is empty wall, bare floor, or a sunlit patch NEXT TO the piece, the photograph has FAILED. If the piece is visibly darker than the surface directly behind it, it has FAILED. The piece must not sit in shade while the room is sunlit.

Keep the light directional and soft so the carving still reads: the form is described by gentle modelling across its faces, not by deep black shadow. Shadows stay open and luminous with visible detail inside them, never crushed to black. Bright does not mean flat, and it does not mean blown out: the wood keeps its full tonal range and its grain.

ONE ROOM, ONE LIGHT, ONE SET OF PHYSICS.

There is exactly ONE light source direction in this photograph. Every shadow in the frame, from the piece, from the props, from the furniture, falls the SAME way, at the same angle, with the same softness. A shadow pointing a different way from its neighbour is the single clearest sign of a fake photograph.

EVERYTHING RESTS ON SOMETHING. The piece meets the floor along its whole base with a real contact shadow that is darkest exactly where the timber touches down and opens up as it moves away. Props sit flat on the top surface with their own small contact shadows. Nothing floats, nothing hovers a few millimetres off the surface, nothing intersects or passes through anything else, and nothing balances in a way that would topple.

SCALE MUST AGREE. The piece, the furniture and the props must all read at a believable size against each other: books, vases and candles are small objects, and if a vase looks nearly as tall as the piece the scale is wrong. Verticals stay vertical. Floorboards, rug edges, wall corners and skirting all run to a consistent perspective. Reflections and highlights agree with the one light source.

THE WOOD MUST HOLD ITS TEXTURE AT THIS VIEWING DISTANCE. This is a Phase One medium format back at f/5.6, which resolves pores and grain across the entire piece even in a full product view. The surrounding room may go soft; the wood may not. If any area reads as a smooth plastic-like or stone-like fill, the image has failed.

THE STYLING IS SPECIFIC TO THIS VARIANT AND DIFFERS FROM THE REFERENCE. Keep the room, the furniture, the camera and the light direction exactly as the reference has them, then dress the piece as follows instead of copying the reference's props.

On the top surface: a tall narrow bud vase in pale sand ceramic, holding three stems of dried eucalyptus, soft sage. Beside it, one thick hardback lying flat in ink blue, its pages softly toned. A small round brass tray resting flat under the vessel. A folded cloth napkin resting flat, stone coloured.

The props are supporting cast, never the subject. They must not cover the top slab edge, must not hide the carved form or any opening in it, and must not outweigh the piece in the frame. NO legible text on any spine, cover or label. Keep every prop within the same restrained palette as the room.

NOT ACCEPTABLE: a seamless studio backdrop or infinity sweep in ANY colour, white, grey, beige or otherwise. No empty featureless void behind the piece. No CGI or 3D-render look. No visible text anywhere in the frame. No watermark. No duplicated or mirrored furniture. No warped verticals. The piece must sit flat and level on the floor with real contact shadow.

ALSO NOT ACCEPTABLE, and these are the ones that make a photograph look generated: a dim or moody room; the piece darker than the wall behind it; a dramatic sunbeam landing on empty floor or empty wall instead of on the product; crushed black shadows with no detail; shadows that fall in more than one direction; anything floating a few millimetres above the surface it should be resting on; props out of scale with the piece; and a tall narrow silhouette where the real object is short and stout.

Do not edit these by hand for a single cell

Every block was proven on a re-run and the generic version of the same instruction is recorded as having failed. Adjectives do not transmit proportion; a number and a named failure mode do. If a block needs changing, change it in the source so all 520 cells inherit it, then regenerate. Editing one prompt in place is how a studio requirement and a studio prohibition ended up in the same instruction set.

Stochastic defects need selection, not better wording

Two identical rows, same product and same prompt, returned hue deltas of 10.1 and 4.6 in the same pass. No prompt fixes a spread that wide because the prompt was identical. When a defect is measurable and cheap to redo, generate three candidates and keep the closest. That cleared 5 of 9 where three rounds of prompt rewriting had each half-worked.

07Checks, and what each one cannot do

Every check here was wrong before a control caught it. Calibrate against known-good cells, never a guessed threshold.

CheckVerdictLimit
Environment, per columntrusted Calibrated per column from 39 known-good cells. One universal threshold flagged 15 of 15 correct bedrooms and 8 of 15 correct macros, which would have condemned 55 good cells.
Studio versus soft roomtrusted Floor-texture over wall-texture. Border variance alone passed a plain room at 20.7, and an edge test scored that room below real studios because plaster is smoother than a backdrop.
Colour, warm woodstrusted Hue against columns P and Q only. Including R poisoned it, because R is the swatch showing every finish at once: it then fired on 3 of 21 untouched originals, which cannot be wrong about their own colour.
Colour, grey finishesunmeasurable Hue carries no signal on grey and the control set had zero grey rows. Every grey cell reads wrong at a median of 10.3, which is an invalid measure, not real defects.
Macro compositionunmeasurable Timber filling the frame has structure at every edge. No threshold separates it from a room.
Geometry and formeye only Four proportion metrics were built and all four were wrong at least once, the last by 26 percent against a hand grid read. Never claim it passed.

Run the control first, every time

Before trusting any check, run it against cells known to be correct. A check that flags known-good cells is broken, not the cells. This single habit caught 55 false condemnations in one pass and stopped a whole-catalogue regeneration that was not needed.

08Publishing

  1. Convert masters to JPEG at quality 92. About 15 percent of the PNG bytes, no visible loss.
  2. Commit and push to the public image host. Git moves a whole batch in one call.
  3. Build {variant_id|column: url} and write =IMAGE(url,4,110,88).
  4. Snapshot the previous cell contents for rollback before writing.
  5. Read back and confirm the formula landed.
  6. Fetch every URL anonymously to prove it serves a real image.

One command: publish.sh <dir> --apply

An IMAGE cell reads back empty whether it worked or failed

The values API returns nothing for =IMAGE() either way, so a readback proves the formula landed and nothing more. Rendering is a human check. Add every new host to the generated-cell classifier, or freshly written cells count as ungenerated and the totals go backwards.

09Standing rules

No plain white backgrounds

Across all three Haussmann storefronts. The only white image that ships is the dimension diagram. A warm neutral studio sweep is a different thing and is required in position 1.

Never generate from a generated image

Using an AI-produced room as the scene reference is what made backgrounds read as synthetic in hue, lighting and texture. The scene comes from an approved image or a real photograph.

Audit the reference, not just the output

When a re-run reproduces the defect it was queued to fix, point the detector at its inputs. Every column S donor was itself a studio sweep, which explained 45 flagged cells in one pass.

Refresh before every audit

Auditing against a snapshot taken before the last publish produces phantom failures on cells already fixed. Re-read the sheet, then measure.
